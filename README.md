# Русская озвучка ARK: Survival Evolved

Программа для Windows: выбирает папку ARK/Steam, устанавливает озвучку отдельных карт и проверяет новые версии при запуске. Друзьям не нужны Python, ElevenLabs или API-ключи.

Скачивание: [последний выпуск](https://github.com/lacost2001/ark-russian-voice/releases/latest).

1. Скачайте и запустите `ARK-Russian-Voice.exe`. Для установки без интернета скачайте полный архив.
2. Закройте ARK, укажите папку игры или библиотеку Steam.
3. Выберите доступные карты и нажмите «Установить / обновить».
4. При следующих запусках программа обновляет выбранные карты, если включена соответствующая галочка. Пока ARK запущен, файлы не заменяются.

Оригиналы находятся в `.ark-russian-voice-backup` внутри игры. Чтобы удалить озвучку, выберите карту и нажмите «Вернуть оригинал». Снятие галочки отключает обновления, но не удаляет установленную озвучку. Steam может вернуть оригиналы при проверке файлов — снова запустите установщик.

## Выпуск 2.2.0: кат-сцены

Для этого выпуска скачайте **новый EXE 2.2**. Старые версии 2.0/2.1 не поддерживают замену видеороликов.

Включены 526 записей из выпуска 2.1 и следующие сцены:

- вступления The Island, Scorched Earth, Aberration и Extinction;
- эпилоги The Island, Scorched Earth и Aberration;
- финал Extinction;
- вступления, концовки и корабельные объявления Genesis 1/2, включая Сантьяго;
- дополнительные общие дорожки диалогов, используемые в сценах Genesis 2.

Семь видеороликов подготовлены в MP4 и WMV. Видеопоток скопирован без перекодирования и проверен по хешу; длительность сохранена. Английский голос отделён от фона с помощью [Demucs](https://github.com/facebookresearch/demucs), русский расположен по временным меткам. Музыка сохраняется, но после разделения звука возможны артефакты. Это дубляж с синхронизацией по времени, не точная анимационная синхронизация губ.

Проверены целостность пакетов, декодирование звука и сохранность видеопотока. Воспроизведение всех новых сцен внутри игры ещё нужно проверить. Поддержка исходных файлов версии `preaquatica`; неизвестные версии программа не перезаписывает.

Это **частичный перевод игры**: 53 досье The Island, часть хроник, записи дополнительных карт и остальные реплики NPC не включены. Неозвученные в оригинале записки Мэй-Инь и Нервы тоже не добавлены. Полный архив означает автономный комплект всех готовых пакетов.

Озвучка синтезирована ElevenLabs (Lily/George; v3/v4 Turbo). Неофициальный проект; ARK и исходные материалы принадлежат их правообладателям. Репозиторий содержит программу, а голосовые пакеты размещаются в Releases. EXE не имеет подписи Windows.

## Для разработчика

Python 3.11+, `pip install -r requirements.txt`. Интерфейс: `launcher.py`. Проверки: `python -m unittest discover -p "test_*.py"`.

Сборка: `pyinstaller --onefile --windowed --name ARK-Russian-Voice --add-data "release_config.json;." launcher.py`.

Каталог `catalog.json` в последнем GitHub Release подписан Ed25519. Открытый ключ встроен в `release_config.json`. Пакеты имеют SHA-256 и размер, проверяются до установки. Программа сохраняет оригиналы и откатывает заменённые файлы карты при ошибке. Между картами установка последовательная: ошибка второй карты не отменяет уже завершённую первую.

Приватный ключ подписи хранится отдельно и никогда не публикуется. Для нового выпуска сохраните прежний открытый ключ, создайте пакеты карт, внесите прежние хеши в `previous_sha256`, подпишите каталог через `sign_catalog.py`. Программа получает новые карты без пересборки, если их формат поддерживается текущим установщиком. Поддерживаются SoundWave-файлы PrimalEarth/Characters, Genesis/HLNA/Glitches/English и Genesis2/HLNA/Chronicles. С версии 2.2 поддерживаются также перечисленные выше кат-сцены: разрешены только известные пути и названия видео.

Обновляются голосовые пакеты, а не сам EXE. Новую версию программы при необходимости скачивают из Releases.
