# Что нового в 2.5.0

Добавлено автообновление приложения с проверкой подписи Ed25519 и SHA-256, сохранением предыдущего EXE и откатом при ошибке замены. Обновление можно отключить отдельной галочкой. Проверены повреждённая загрузка, запрет отката версии и восстановление при сбое запуска.

Тёмный интерфейс с карточками карт, прокруткой и отдельной проверкой файлов. «Установить / исправить» повторно скачивает повреждённые пакеты и восстанавливает повреждённые резервные копии, если найден оригинал с правильной контрольной суммой. При временном сетевом сбое выполняются до трёх попыток загрузки. Повреждённые настройки заменяются корректными значениями. Ошибки записываются в локальный журнал, доступный кнопкой в программе.

«Проверить файлы» проверяет совместимость выбранных пакетов и оригиналов, не меняя файлы игры; отсутствующие пакеты могут быть скачаны в кэш. Неизвестную версию игры или отсутствующий оригинал без надёжной копии программа автоматически исправить не может. В таком случае она показывает причину и дальнейшее действие.

Журнал хранится только на компьютере, автоматически никуда не отправляется. Проверено 29 тестов: установка, повторная установка, откат при сбое, восстановление, подписи, повреждённые пакеты, копии, настройки и повтор загрузки. После принудительного завершения посреди нескольких пакетов часть карт может быть уже обновлена; следующий запуск повторно проверит их.

# Русская озвучка ARK: Survival Evolved

ARK: Survival Evolved — программа 2.5.0

УСТАНОВКА
Распакуйте весь архив. Закройте ARK. Запустите ARK-Russian-Voice.exe, укажите папку игры или Steam, выберите карты и нажмите «Установить / исправить».
«Общие реплики HLN-A» — приветствия и реакции мини-компаньона, используемые на разных картах. Этот пункт можно поставить вместе с любой картой.
Резервные копии оригиналов создаются перед заменой. Для отмены выберите те же пункты и нажмите «Вернуть оригинал».
Снятие галочки само по себе ничего не удаляет. Сервер и сохранения не изменяются. Workshop-мод не нужен.

СОДЕРЖИМОЕ
1 950 файлов: 1 936 аудиофайлов и 14 вариантов видеороликов (MP4/WMV).
В версии 2.3 добавлены 1 353 аудиофайла: повседневные и боевые реплики HLN-A и Роквелла, задания Genesis, 63 недостающих досье, дополнительные хроники, приветствия и эмоции мини-HLN-A.
Включены ранее подготовленные записки, досье, вступления и финальные сцены.
Карты: The Island, Scorched Earth, Aberration, Extinction, Genesis 1 и 2, Ragnarok, Valguero, Crystal Isles, Lost Island и Fjordur. На дополнительных картах пакет содержит соответствующие досье существ, а не новую сюжетную кампанию.
Исправлены ранее оставшиеся английскими досье The Island. Старые неправильные записи распознаются по контрольным суммам; для их обновления необходима сохранённая установщиком резервная копия оригинала.

ОБНОВЛЕНИЯ
Программа 2.5.0 поддерживает составные голосовые пакеты. Само приложение и голосовые пакеты обновляются автоматически при включённых соответствующих настройках. Для первого перехода с 2.4 и старше скачайте новый EXE вручную. Далее приложение проверяет подпись обновления, скачивает его, закрывается и запускается в новой версии. Предыдущий EXE сохраняется рядом с окончанием .previous; при ошибке замены или создания процесса выполняется откат. Не устанавливайте программу в папку только для чтения. Без интернета доступна установка из полного архива.
При запуске программа проверяет и обновляет выбранные голосовые пакеты. Старая часть 2.2 используется повторно, поэтому ради новых реплик не требуется заново скачивать кат-сцены, если пакет уже есть рядом с программой или в её кэше.
Для полностью автономной установки сохраните все файлы из полного архива рядом с программой.
API-ключ ElevenLabs и платная подписка пользователю не нужны.

ПРОВЕРКА И ОГРАНИЧЕНИЯ
Сборка предназначена для версии preaquatica. Неизвестные исходные файлы программа не заменяет.
Проверены структура файлов, декодирование нового звука, подпись каталога, контрольные суммы и восстановление оригиналов на тестовых файлах. Воспроизведение каждой реплики в самой игре ещё не проверено.
В кат-сценах сохранены видеоряд и длительность. Английская речь отделена от музыки; возможны артефакты разделения и несовпадение движения губ.
Не заменены музыка, звуковые эффекты, дыхание и стоны. Десять сильно обработанных фоновых шёпотов Роквелла оставлены оригинальными: надёжно восстановить их текст не удалось. Служебный тестовый голос также не заменён.
Новые звуковые события для записок, у которых в оригинале нет аудиодорожки, не добавляются.
Программа не подписана сертификатом Windows.

## Исходный код

Python 3.11, Tkinter, cryptography. Для сборки Windows EXE: PyInstaller. Каталоги подписаны Ed25519; приватный ключ в репозитории отсутствует. Исходные игровые файлы не включены в репозиторий.

Разделение фоновой музыки в роликах: [Demucs](https://github.com/facebookresearch/demucs).
